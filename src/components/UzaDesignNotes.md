# UZA UI system

The marketplace uses a mobile-first, premium visual language: white surfaces, deep ink typography, UZA violet primary actions, soft gray page backgrounds, 16px-28px radii, subtle borders and restrained shadows.

## Navigation

Desktop: logo, primary links, authentication/profile actions.
Mobile: logo, authentication/profile action, menu button; the menu expands all navigation links and keeps authentication actions accessible instead of hiding them.

## Connected account

When authenticated, hide Sign in and Sign up from the header. Show the user's avatar (or initials fallback) and link it to the profile/dashboard area.

## Marketplace cards

Product cards prioritize image, title, condition, final UZA price, location, verification badge and favorite action. Never expose seller contact information.

## Workflow surfaces

Use consistent status badges for draft, pending review, published, rejected, scheduled, in progress, completed and cancelled. Critical actions require clear confirmation and error feedback.

## Mobile

No desktop-only controls should disappear without an equivalent mobile interaction. Forms stack to one column, tables become cards or horizontally scrollable panels, and primary actions remain reachable.
